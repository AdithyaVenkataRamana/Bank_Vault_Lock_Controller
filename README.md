# Bank_Vault_Lock_Controller
## Hardware Demonstration

This project demonstrates the implementation of a Bank Vault Lock Controller using Verilog HDL and a Xilinx Spartan-6 FPGA.

The design implements a digital access-control mechanism where the configured input conditions are checked to control the vault's Open output.

Inputs and Output
VP1: Vault input
VP2: Vault input
P: Password/control input
Open: Vault open status output

The controller evaluates the input conditions and activates the Open output when the required access condition is satisfied.
